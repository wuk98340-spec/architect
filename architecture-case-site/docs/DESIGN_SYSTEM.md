# ARCHITECT 设计系统 v1.0

**定位**：建筑档案、研究型、克制、编辑出版感；让图片、图纸、文字与证据能被清楚地阅读、比较和引用。

**服务对象**：建筑学学生首先要快速找到可研究的案例；教师需要横向比较和进入资料；研究者需要判断资料来源、完整度与引用边界。

**核心原则**

1. 先建立资料秩序，再建立视觉情绪。
2. 图片不是装饰背景；每张图都应标明它是照片、图纸、分析图或证据图。
3. 容器只在需要分组、筛选或承载交互时使用；不能把每一段文字都装进卡片。
4. 用细分隔线、版面留白与排版对比建立层级，不使用阴影、玻璃或大面积渐变。
5. 设计系统的识别组件是 **证据栏（Evidence rail）**：在案例、图像或章节旁显示年份、地点、类型、资料状态和来源入口。它表达档案关系，不作为装饰性的编号。

## 1. 页面骨架、最大宽度与栅格

### 页面宽度

| 层级 | 规则 | 用途 |
| --- | --- | --- |
| Site canvas | `max-width: 1440px` | 首页、案例列表、宽幅图像、比较型内容 |
| Reading column | `max-width: 760px` | 正文、摘要、方法说明、长段落 |
| Research column | `max-width: 960px` | 信息表、引用、双栏图文、分析图 |
| Full bleed media | 允许延伸到 site canvas | 首页主图、总平/剖面、图像组 |

页面在 1440px 以上不继续放大内容；只增加两侧留白。这样既保留图纸阅读空间，也避免研究文本过宽。

### 栅格

| 视口 | 栅格 | 列间距 | 页面边距 | 常用分配 |
| --- | ---: | ---: | ---: | --- |
| Desktop `≥ 1280px` | 12 列 | 24px | 48px | 正文 7 列；证据栏 2 列；图像 12 / 7 / 5 列 |
| Tablet `600–1279px` | 8 列 | 20px | 32px | 正文 5–6 列；图像 8 / 4 列 |
| Mobile `< 600px` | 4 列 | 16px | 20px | 正文和图像 4 列；小型并列信息 2 列 |

栅格用于对齐，不能强迫每个内容块都填满。案例详情页的正文与来源应沿同一左缘对齐；证据栏可在桌面端置侧、移动端置于标题下方。

## 2. 色彩

采用纸张、中性墨色与一枚低饱和矿物色。首页可用深墨底承载影像，但不建立第二套品牌色。

| Token | 色值 | 用途 |
| --- | --- | --- |
| `--paper` | `#F3F1EB` | 主页面底色、正文阅读面 |
| `--paper-deep` | `#E7E3D9` | 表格表头、浅层分组、图片说明底 |
| `--ink` | `#20231F` | 主文字、主要边线、图标 |
| `--ink-muted` | `#62665F` | 次级说明、元数据、非当前导航 |
| `--line` | `#C8C6BC` | 细分隔线、表格、控件边界 |
| `--field` | `#303830` | 深色图像区、首页影像区、反白文字背景 |
| `--field-muted` | `#AEB5A9` | 深色背景的次级文字 |
| `--oxide` | `#98513B` | 当前筛选、资料缺口、少量重点链接；不可用于大面积底色 |
| `--status-good` | `#4B6754` | 高资料完整度 / 已核验状态 |

使用规则：正文默认使用纸底墨字；深底只用于影像或一段明确的策展内容；`oxide` 每屏最多一个主用途。禁止渐变作为信息层级手段。

## 3. 字体与排版层级

建议加载一套中文衬线阅读字体与一套中文无衬线界面字体；未加载时使用系统后备。数据、编号与英文缩写采用等宽字体，避免用等宽字体写中文正文。

```text
Reading / 标题与长文："Noto Serif SC", "Source Han Serif SC", Songti SC, STSong, serif
Interface / 导航与控件："Noto Sans SC", "Source Han Sans SC", PingFang SC, Microsoft YaHei, sans-serif
Data / 年份、编号、坐标："IBM Plex Mono", "SFMono-Regular", Consolas, monospace
```

| 层级 | Desktop | Tablet | Mobile | 字重 / 行高 | 使用场景 |
| --- | ---: | ---: | ---: | --- | --- |
| Display | 64px | 52px | 40px | 600 / 1.05 | 首页论点、专题标题；每页最多一个 |
| H1 | 48px | 40px | 32px | 600 / 1.12 | 案例标题 |
| H2 | 32px | 28px | 24px | 600 / 1.2 | 章节标题 |
| H3 | 22px | 20px | 18px | 600 / 1.3 | 小节、案例卡标题 |
| Lead | 21px | 19px | 18px | 400 / 1.6 | 案例摘要、导语 |
| Body | 17px | 17px | 16px | 400 / 1.75 | 正文 |
| Body small | 15px | 15px | 14px | 400 / 1.65 | 图注、表格、引用 |
| Metadata | 12px | 12px | 12px | 500 / 1.4 | 年份、地点、资料状态 |

中文标题不做全大写和过度字距；英文 archive label 可用 11–12px、`0.08em` 字距。标题与正文用不同字体角色，而不是在所有区域混用大号无衬线。

## 4. 间距尺度

以 4px 为基础单位，不使用随意的 13px、19px、37px 间距。

| Token | 值 | 典型用途 |
| --- | ---: | --- |
| `--space-1` | 4px | 图标与文字、细小内部间距 |
| `--space-2` | 8px | 元数据行、紧凑控件 |
| `--space-3` | 12px | 图注、按钮内距 |
| `--space-4` | 16px | 表单字段、列表项 |
| `--space-5` | 24px | 卡片内部、标题与引言 |
| `--space-6` | 32px | 内容块之间 |
| `--space-7` | 48px | 小节与模块之间 |
| `--space-8` | 64px | 页面主要区段 |
| `--space-9` | 96px | 首页大区段 |
| `--space-10` | 128px | 仅用于首页起始或专题开场 |

正文段落间距为 16px；H2 上方 64px、下方 24px；图像与图注之间 12px；图像组之间 32px。

## 5. 图片比例、图纸与裁切

图片区分内容类型；不把图纸当作被裁切的摄影封面。

| 内容 | 容器比例 | `object-fit` | 裁切规则 |
| --- | --- | --- | --- |
| 案例索引缩略图 | `4:3` | `cover` | 焦点优先为建筑主体；允许裁切环境边缘，不裁切建筑主体 |
| 首页主图 | `3:2`（移动端 `4:5`） | `cover` | 使用单张有明确视线方向的照片；标题置于低信息密度区域 |
| 精选案例图片 | `3:2` | `cover` | 保持一组内比例一致 |
| 详情页摄影 | `3:2` 或原图自然比例 | `cover` / `contain` | 单图可自然比例；连续图组固定 `3:2` |
| 总平、平面、剖面、构造图 | 不设固定比例 | `contain` | 完整显示，不裁切；使用浅纸底与边线 |
| 分析图、对比图 | `4:3` | `contain` | 图像优先，允许留白 |

每张研究图片必须有图注：图号 / 图像类型、内容说明、来源、版权或使用备注。不可使用渐变叠层来替代图注。

## 6. 组件规则

### 卡片

- 卡片仅用于案例索引、相关案例、资料模块；正文、章节和引用不用卡片包裹。
- 外观：`border-radius: 0`，1px `--line` 边线，无默认阴影。
- 案例索引卡为 `4:3` 缩略图 + 标题 + 单行证据栏（年份 / 地点 / 资料状态）；不在图片上堆叠摘要、标签与按钮。
- Desktop 列表最多 4 列；Tablet 2–3 列；Mobile 2 列。研究密度不足时宁可留白，不硬填五列。
- 精选案例使用“图像 + 说明 + 证据栏”的编辑版式，不使用普通卡片容器。

### 标签与资料状态

- 标签为信息分类，不作装饰性胶囊。使用 1px 下边线或方形描边，`border-radius: 0`。
- 单个案例展示不超过 3 个标签；完整关键词进入详情页资料区。
- 状态只使用：`已核验`、`待复核`、`资料有限`、`图纸缺失`。颜色辅助区分，但文本不可省略。

### 按钮与链接

| 类型 | 外观 | 使用 |
| --- | --- | --- |
| Text link | 正文墨色 + 下划线偏移 3px | 来源、返回、次级操作 |
| Primary action | 深墨实底、白字、直角、最小高度 44px | “浏览案例”“进入研究”每屏最多一个 |
| Secondary action | 透明底、1px 墨色描边、直角 | 筛选、比较、展开资料 |
| Quiet action | 无边框文字 + 箭头 | 上一项 / 下一项、目录内操作 |

按钮文案使用明确动词，例如“查看案例”“清除筛选”“展开资料”，不用“了解更多”。

### 筛选器

- 桌面端：案例列表标题下方的常驻筛选条，依次为搜索、类型、地区、建造状态、排序、清除。
- 平板与手机端：筛选以页面内折叠区或全屏抽屉呈现，但默认关闭；已选条件和结果数量始终可见。
- 筛选分组采用 `fieldset + legend`；选项是可点击的文本行或方形标签，不使用圆角 chips 云。
- 每次筛选变化应更新结果数、URL 参数和“清除筛选”状态。

### 证据栏（共享识别组件）

```text
2015   成都 / 中国   城市综合体   已核验   6 项主要来源 →
```

- 桌面端可占 2 列并贴近主内容；移动端放在标题或图注下。
- 使用 Metadata 字号、细分隔线和等宽年份；不使用彩色徽章堆叠。
- 首页用它概括案例；列表页用它辅助判断；详情页用它连接来源与资料状态。

## 7. 响应式规则

### Desktop `≥ 1280px`

- 12 列，列表默认 4 列。
- 首页主图与导语使用 7:5 或 8:4 的不对称栅格；筛选不遮挡首屏。
- 详情页可使用正文 + 证据栏的 7:2 关系；图纸可跨 12 列。

### Tablet `600–1279px`

- 8 列，列表 2–3 列。
- 导航保持单行；筛选转为可展开区域。
- 详情页证据栏移至标题下方，长表格允许横向滚动但必须保留表头。

### Mobile `< 600px`

- 4 列，列表 2 列；只有标题特别长或图纸索引才改为单列。
- 文章正文全宽但控制行长；最小左右边距 20px。
- 首屏不超过 `100svh`，不以全屏固定抽屉作为默认状态。
- 详情内容采用连续滚动和章节锚点；不使用固定高度 slide deck 承载长表格或长文。
- 点击目标最小 44 × 44px，筛选与排序须可单手操作。

## 8. 三类页面的共同组件

| 组件 | 首页 | 列表页 | 详情页 |
| --- | --- | --- | --- |
| Global header | 品牌、案例库、专题、关于、搜索 | 同左 | 品牌、返回案例库、目录 |
| Archive masthead | 网站论点 + 一张主图 | 页面标题 + 结果数 | 案例标题 + 摘要 + 证据栏 |
| Evidence rail | 精选案例与时间索引 | 每个案例条目 | 标题、图片、章节资料 |
| Figure + caption | 主页主图、精选图片 | 缩略图辅助信息 | 摄影、图纸、分析图、来源 |
| Section heading | 专题 / 精选 / 方法 | 结果与分组 | 章节与锚点 |
| Footer | 资料范围、方法、版权 | 同左 | 来源、版权、相关案例 |

页面职责必须清楚：

- **首页**：说明资料库的价值，并引导进入检索、专题或一项精选研究；不重复完整案例列表。
- **列表页**：完成搜索、筛选、比较和进入案例；这是唯一完整索引。
- **详情页**：连续阅读、跳转章节、查看图纸与来源；不模拟课堂幻灯片。

## 9. 交互状态

| 状态 | 链接 / 按钮 | 卡片 | 输入与筛选 |
| --- | --- | --- | --- |
| Default | 原有边线或下划线 | 无阴影、图片静止 | 1px `--line` |
| Hover | 文字下划线加深；按钮底色由 `--ink` 到 `--field` | 图片轻微放大至 `1.015`；证据栏线条加深 | 边线改为 `--ink` |
| Focus-visible | 2px `--oxide` 外轮廓，`outline-offset: 3px` | 同左，整卡可见焦点 | 同左，不只改变颜色 |
| Active / Selected | `--oxide` 作为细下划线或左边线 | 不改变立体效果 | 显示“已选”文本与清除入口 |
| Disabled | 文字与边线使用 `--ink-muted` 的 55% | 不可点击、不降低到难以辨认 | 不响应操作；保留原因或提示 |

不使用持续漂浮、自动轮播、过度位移或全页动画。若使用过渡，限制为 160–220ms；`prefers-reduced-motion` 下取消图片缩放与平滑滚动。
