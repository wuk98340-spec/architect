02

项目概述与设计概念

泰州科学发展观展示馆把主题展示、稻河历史街区、多儿巷一号故居、中央水庭和绿色技术整合成一条有起承转合的参观叙事。

资料中的概念

同济大学博物馆资料称项目基地确立了“和谐与发展”的总体设计定位，因时就地，建立大气整体、主轴统领、重点突出的总体格局；泰州市住建局资料强调空间序列因势就地，形成主题明确、起承转合、一气呵成的建筑叙事篇章。

综合判断

项目将政治主题展示、旧城历史街区、多儿巷一号故居、中央水庭和绿色技术组织为同一条参观叙事，使建筑本体成为“科学发展”主题的空间化表达。

03

核心设计策略

01

用参观序列整合主题展示与历史节点

面对的问题
科学发展观主题展示容易停留在室内文本陈列，历史故居也容易成为孤立景点。
具体做法
以序厅、水庭、滨水玻璃长廊、室外展示区、多儿巷一号和民居群组织逐层递进的参观路径。
建筑效果
参观者在移动中经历由展馆到故居、由现代展示到历史现场的转换，形成明确的叙事高潮。
证据
Directly sourced and AI synthesis
可迁移方法
纪念展示建筑可以把真实历史资源作为参观高潮，而不是只依赖室内展陈完成叙事。

02

中央水庭作为尺度转换和空间锚点

面对的问题
基地夹在历史街区与城市道路之间，旧城小尺度和公共建筑大尺度存在冲突。
具体做法
以南北两组宅院交融的展厅建筑凸显长达百米的中央水庭，并通过滨水玻璃长廊导引参观。
建筑效果
水庭成为对景、缓冲、导览和旧城尺度转换的复合空间。
证据
Directly sourced and image-supported synthesis
可迁移方法
旧城边界公共建筑可用水院、庭院或长廊消解体量，并建立慢行体验。
图像 img_01 来源 s1来源 s3
03

民居构件的现代建筑语法转译

面对的问题
地方性表达容易退化为仿古屋顶或表面装饰。
具体做法
将黛瓦灰墙青砖色调、左右逢源、灰砖尺度、堆瓦窗花和淮脊空隙分别转译为色彩、钢构架、7.5 公分横向肌理、几何钢架和屋脊长条空隙。
建筑效果
建筑保持现代展示馆构成，同时获得泰州传统民居的尺度和文化意味。
证据
Directly sourced
可迁移方法
地域转译应同时处理色调、尺度、构件关系和空间组织，而不是复制符号。
图像 img_01图像 img_02 来源 s1
04

绿色技术嵌入主题表达

面对的问题
科学发展主题若只靠展板表达，建筑本体的说服力不足。
具体做法
采用自然采光、下沉绿化庭院、雨水收集、太阳能利用、屋面遮阳板与光伏结合、双层中空玻璃等策略；补充资料还提到地源热泵、绿色照明和透水地面。
建筑效果
建筑的环境技术与展示主题形成互证，使可持续理念可以通过空间和运行策略被感知。
证据
Directly sourced with supplementary source
可迁移方法
主题展示建筑的技术系统应尽量和庭院、采光、屋面、雨水景观等可感知空间结合。

信息缺口与冲突

  • Professional architecture media：Targeted searches did not retain a gooood, ArchDaily, ArchDaily China, Archiposition / 有方 or comparable professional architecture media project report.
  • Project name variant：The Taizhou government page uses '泰州科学发展观展示馆', while the Tongji University Museum exhibition page uses '泰州（中国）科学发展观展示中心'. They are treated as the same project because location, architect and project description align.
  • Green building star rating：The government page describes green and intelligent building goals and lists sustainability measures. The Nanjing University visit report states it reached national green building three-star standard, but no certification document was retained.
  • Structure and construction detail：Public sources do not provide reliable structural system, drawings, facade details, construction process or post-occupancy performance data.
