# Architecture Analysis Taxonomy

Use this reference to select professional analysis dimensions for an architecture case. Do not mechanically apply every dimension. The goal is to explain the strongest evidence-backed chain from concept to built work.

## How To Use This Reference

1. Identify the case type and the available evidence: official text, interviews, drawings, photographs, detail images, material notes, construction notes, awards, or professional media analysis.
2. Map the evidence into the three analysis layers below.
3. Select the strongest 3-5 strategies or transferable methods. Prefer topics supported by sources, plans, sections, photographs, or detail drawings.
4. If construction, technical metrics, or details are not supported, state the limitation briefly instead of inferring from common practice.

## Three-Layer Analysis Frame

### 1. Conceptual Exploration

Use this layer to explain how the project finds its breakthrough direction before it becomes a building.

- Diagnosis: project problem, site conflict, program constraint, cultural issue, technical challenge, available resource.
- Positioning: regional culture, contemporary ambition, urban role, user group, social goal, spatial or experiential goal.
- Strategy: guiding principle, resource allocation, hierarchy of design responses, relationship between problem and solution.
- Imagery and appearance: sketches, diagrams, prototypes, image intentions, form-generating keywords, atmospheric intent.
- Naming and expression: project name, core narrative, concept phrase, public communication, symbolic framing.

### 2. Architectural Language Generation

Use this layer to explain how an abstract idea becomes space, form, organization, and experience.

- Function: users, activities, program sequence, public/private relation, open/closed relation, program hybridization or translation.
- Layout: site plan, plan organization, vertical organization, entries, circulation, relation to roads, landscape, urban interface, external constraints.
- Composition: massing operation, spatial sequence, interface treatment, structure as spatial form, service-space integration, envelope, openings, roof, base.
- Place and atmosphere: body experience, visual experience, daylight, shadow, material perception, interior-exterior relation, landscape penetration, human scale.

### 3. Construction Quality Control

Use this layer to explain how design intent becomes built quality. Only write claims supported by reliable evidence.

- Construction language: structural frame, column grid, load-bearing logic, wall/envelope system, roof, base, platform, landscape ground.
- Materials and craft: main materials, selection logic, processing method, craft, relation to locality, economy, durability, expression.
- Tectonic logic: module, setting-out, section layers, jointing, facade connection, roof/wall/ground detail.
- Physical performance: rain, dust, shading, ventilation, insulation, environmental control, indoor-outdoor transition, landscape connection, material transition.
- Construction control: site guidance, construction difficulty, special building procedure, prefabrication, assembly, site fabrication, mockup, quality-control measure, difference between design intent and built result.

## Strategy Dimensions

Use these dimensions as a menu for choosing 3-5 focused strategies. They can belong to one or more of the three layers above.

- Site strategy: terrain, block structure, urban edge, landscape view, historical context, access sequence.
- Program strategy: mixed use, zoning, vertical organization, circulation, public/private gradient, pedestrian/vehicle separation.
- Spatial strategy: sequence, publicness, openness, threshold, courtyard, atrium, corridor, roof, shared space.
- Massing strategy: volume generation, setback, cutting, lifting, courtyard formation, tower-podium relation.
- Facade strategy: envelope, opening, shading, curtain wall, proportion, solid/void rhythm, texture.
- Structural strategy: long span, cantilever, prefabrication, timber, steel, concrete, hybrid system.
- Material and tectonic strategy: material choice, local material, new material, detail expression, construction logic.
- Regional culture translation: traditional space, local symbols, craft, climate, contemporary life pattern.
- Green and climate strategy: natural ventilation, daylighting, shading, rainwater, vertical greenery, low-carbon material.
- User experience: route, pause, viewing, social activity, learning, consumption, ritual, arrival.
- Transferable lesson: what architecture students, competitors, case-library editors, or design researchers can learn.

## Case Type Emphasis

- Cultural building: emphasize publicness, urban interface, exhibition route, symbolic form, civic identity.
- Education building: emphasize learning space, informal exchange, campus relationship, flexible use.
- Hotel: emphasize arrival, view, guestroom module, public zone, facade landmark quality.
- Housing / apartment: emphasize unit type, view, privacy, amenities, facade order.
- Commercial complex: emphasize circulation, tenant mix, interface, entries, vertical transport, consumption route.
- Renovation: emphasize old-new relation, retained structure, material dialogue, historical memory.
- Rural / cultural tourism: emphasize local material, village fabric, operation model, low-cost construction.
- Green building: emphasize climate response, energy strategy, construction details, ecological systems.

## Strategy Writing Requirements

For each selected strategy or method, write:

- Method name.
- Design problem: the constraint, need, opportunity, or contradiction the method responds to.
- Specific approach: what the project does spatially, tectonically, formally, operationally, or environmentally.
- Architectural effect: what the method changes in use, experience, performance, built quality, or urban relation.
- Evidence source: source IDs, source links, drawings, image IDs, or clear notes that the claim is AI synthesis.
- Related image or drawing: embed the downloaded local image in `case.md` when a plan, section, facade, diagram, detail, or photo directly supports the claim; keep the source URL in `case.json`.
- Transferable method: what can be learned without copying the project literally.

## Evidence Discipline

- Prefer drawings, diagrams, official descriptions, interviews, awards, and high-quality architecture media for strategy claims.
- Mark inferred ideas as AI synthesis when the source does not directly state them.
- Separate `来源明确` from `基于资料的归纳判断`.
- Do not fabricate structure, material, climate performance, area, FAR, building density, construction sequence, construction difficulty, or year.
- For construction details and technical metrics, absence of evidence is a finding. State the limitation briefly and keep the analysis focused on confirmed evidence.
- If evidence is weak, reduce certainty and move the issue to `uncertain_or_conflicting_info`.
